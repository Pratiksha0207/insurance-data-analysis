# End-to-End Insurance Risk & Customer Churn Analytics System

An advanced data engineering and data science project simulating an enterprise insurance database architecture. This system processes customer, policy, and claims data, applies machine learning predictive engines, automates corporate financial reporting, and serves an executive business intelligence dashboard.

## 🛠️ Tech Stack & Architecture
- **Data Querying & Aggregation:** SQL (CTEs, Window Functions, Named Joins)
- **Predictive AI Engine:** Python (Pandas, NumPy, Scikit-Learn Random Forest Classifier)
- **Automation Pipeline:** Advanced Excel (Power Query, Dynamic Arrays, English VBA Macros)
- **Business Intelligence Reporting:** Power BI Desktop (DAX Data Modeling, KPI Block Layouts)

## 📁 Project Structure & File Deliverables
- `generate_data.py`: Multi-table production mock relational database generator using advanced random seed distributions.
- `sql_analysis.py`: Analytical data layer using intermediate SQL connections to merge metrics into a master table.
- `churn_model.py`: Advanced Python pipeline executing feature engineering and machine learning churn-risk scoring (74.5% Accuracy).
- `Insurance_Automation.xlsm`: Excel operational file containing a responsive Power Query structure and an automated English VBA high-risk PDF report generator.
- `Insurance_Risk_&_Churn_Analytics.pbix`: Executive Power BI dashboard featuring synchronized dark-mode visualization layers and custom DAX business loss metrics.

## 📊 Business Metrics Solved (DAX Formulas Included)
- **Total Portfolio Revenue**: Evaluates aggregate active financial exposure.
- **Portfolio Loss Ratio %**: Computes claims expense efficiency against top-line collection arrays.
- **AI-Risk Distribution Tiers**: Tracks low, medium, and high operational attrition threat matrices.
